    • CSS notes

    The format for styling is as follows:

    Selector {

        Property: Value;

    }

  • selector
    • Targets the specefic element to style.
  • property
    • Specefies which kind of styling will be applied
  • Value
    • Specefic setting applied to that property

    • There are three ways to style:

  • Inline CSS
    • When you apply the styling directly onto the HTML line.
  • Internal CSS
    • When you apply the styling in the <head> section of the HTML document.
  • External CSS
    • When you apply the styling via a separate CSS sheet. This is the most common method used.

    • The default styling for a lot of elements is "display: block." This ensures the element takes the full width of the container.

    Universal Selector ( * )

    This Selector applies to all elements on the page, however is overridden by all other style types. It's good for setting a default start point like Margin and padding to 0 for the page. The order of application is as follows: Inline CSS, Internal ID, External, Universal.

    There is a way to override the order of application, and that is with the !important declaration.

    Properties

    display: inline is used for smaller text patches in line, or specific styles or parts of a paragraph.

    display: inline-block utilizes both inline and block properties, allowing elements to sit inline while still accepting width and height values.

    Margin

    Margin is the space outside an element's border.

    Margin-top: 10px; This adds space above each list item.

    • Utilizing this, I can target the spacing of items.

    Margin: 10px; applies the spacing to all four sides.

    Margin: 10px 20px; applies the spacing to the top/bottom and left/right respectively.

    Padding

    Padding is the space between the content and the border of the element.

    Padding: 10px; applies the padding to all four sides.

    Padding: 10px 20px; applies the padding to the top/bottom and left/right respectively.

    Strings

    Strings are sequences of characters enclosed in single or double quotes. They can be manipulated using various methods and operators.

    To access a character from the string use a bracket notation and pass in the index number:

    let message = "Hello, World!";

    console.log(message[0]); // Output: H

    \n Newline. You can use this to create a new line in your string.

    let message = "Hello, World!";

    console.log(message + "\n" + "This is a new line.");

    Escaping strings

    let message = "He said, \"Hello!\"";

    console.log(message); // Output: He said, "Hello!"

    String Interpolation and Template Literals

    let name = "Alice";

    let message = `Hello, ${name}!`; // Using template literals

    console.log(message); // Output: Hello, Alice!

    Methods

    Math

    Working with the Number Data type

    • Definition: JavaScript's Number type includes integers, floating-point numbers, Infinity and NaN. Floating-point numbers are numbers with a decimal point. Positive Infinity is a number greater than any other number while -Infinity is a number smaller than any other number. NaN (Not a Number) represents an invalid numeric value like the string "Jessica".

    Common Arithmetic Operations

    • Addition Operator ( + ) calculates the sum of two values.
    • Subtraction Operator ( - ) calculates the difference between two values.
    • Multiplication Operator ( * ) calculates the product of two values.
    • Division Operator ( / ) calculates the quotient of two values.
    • Remainder Operator ( % ) calculates the remainder of a division operation.
    • Exponentiation Operator ( ** ) calculates the power of a value.

    Calculations with Numbers and Strings

    • Explanation: When you use the + operator with a number and a string, JavaScript will coerce the number into a string and concatenate the two values. When you use the -, * or / operators with a string and number, JavaScript will coerce the string into a number and the result will be a number. For null and undefined, JavaScript treats null as 0 and undefined as NaN in mathematical operations.
    • Example:

      • let num = 5;

      let str = "10";

      console.log(num + str); // Output: "510" (string concatenation)

      console.log(num - str); // Output: -5 (number subtraction)

      console.log(num * str); // Output: 50 (number multiplication)

      console.log(num / str); // Output: 0.5 (number division)

      const result1 = null + 5;
      console.log(result1); // Output: 5
      console.log(typeof result1); // Output: "number"

      const result2 = undefined + 5;
      console.log(result2); // output: NaN
      console.log(typeof result2); // Output: "number"

    Operator Precedence

    • This is basically PEMDAS from school -_-; only thing of note is that exponets get calculated from right to left. 2**3**4 means you start from 4, then 3, then 2. So 3**4 = 81, then 2**81 = a really big number.
    • Example:

      let x = 5;
      let y = ++x; // y is 6, x is 6
      let z = x++; // z is 6, x is 7

    Increment and Decrement Operators

    • Increment operator is used to increase the value by one. The prefix notation `++num` increments the value before using it, while the postfix notation `num++` uses the original value before incrementing it. Decrement operator works similarly but decreases the value by one.
    • Example:

      let x = 5;
      console.log(++x); //output: 6
      console.log(x); //output: 6

      let y = 5;
      console.log(y--); //output: 5
      console.log(y); //output: 4

    Compound Assignment Operators

    • Addition (+=) performs addition and assignment in one operation.
    • Subtraction (-=) performs subtraction and assignment in one operation.
    • Multiplication (*=) performs multiplication and assignment in one operation.
    • Division (/=) performs division and assignment in one operation.
    • Remainder (%=) performs remainder calculation and assignment in one operation.
    • Exponentiation (**=) performs exponentiation and assignment in one operation.
    • Example:

      let x = 5;
      x += 3; // x is now 8
      x -= 2; // x is now 6
      x *= 4; // x is now 24
      x /= 6; // x is now 4
      x %= 3; // x is now 1
      x **= 2; // x is now 1

    Booleans and Equality

    • A Boolean is a data type that can only be true or false.
    • Equality operators perform type coercion before checking if two values are equal (==) or not equal (!=).
    • Strict equality operators check if two values are equal and have the same data type (===) or not equal (!==).
    • example:

      let x = 5;
      let y = "5";
      console.log(x == y); // Output: true (type coercion)
      console.log(x === y); // Output: false (no type coercion)
      console.log(x != y); // Output: false (type coercion)
      console.log(x !== y); // Output: true (no type coercion)

    Comparison Operators

    • Greater than (>) checks if the left value is greater than the right value.
    • Less than (<) checks if the left value is less than the right value.
    • Greater than or equal to (>=) checks if the left value is greater than or equal to the right value.
    • Less than or equal to (<=) checks if the left value is less than or equal to the right value.
    • Example:

      let x = 5;
      let y = 10;
      console.log(x > y); // Output: false
      console.log(x < y); // Output: true
      console.log(x >= 5); // Output: true
      console.log(y <= 10); // Output: true

    Unary Operators

    • Unary plus (+) converts a value into a number.
    • Unary minus (-) converts a value into a number and makes it negative.
    • Logical NOT operator (!) converts a value into its boolean opposite.
    • Example:

      let x = "5";
      console.log(+x); // Output: 5 (number)
      console.log(-x); // Output: -5 (number)
      console.log(!true); // Output: false

    Bitwise Operators

    • Bitwise AND (&) performs a bitwise AND operation on two values.
    • Bitwise OR (|) performs a bitwise OR operation on two values.
    • Bitwise XOR (^) performs a bitwise XOR operation on two values.
    • Bitwise NOT (~) inverts the bits of a value.
    • Left shift (<<) shifts the bits of a value to the left by a specified number of positions.
    • Right shift (>>) shifts the bits of a value to the right by a specified number of positions.
    • Unsigned right shift (>>>) shifts the bits of a value to the right by a specified number of positions, filling with zeros.
    • Example:

      let x = 5; // Binary: 0101
      let y = 3; // Binary: 0011
      console.log(x & y); // Output: 1 (Binary: 0001)
      console.log(x | y); // Output: 7 (Binary: 0111)
      console.log(x ^ y); // Output: 6 (Binary: 0110)
      console.log(~x); // Output: -6 (Binary: 1010)
      console.log(x << 1); // Output: 10 (Binary: 1010)
      console.log(x >> 1); // Output: 2 (Binary: 0010)
      console.log(x >>> 1); // Output: 2 (Binary: 0010)

    Conditional Statements, Truthy Values, Falsy Values and the Ternary Operator

    • if/else if/else: An if statement takes a condition and runs a block of code if that condition is truthy. If the condition is false, then it moves to the else if block. If none of those conditions are true, then it will execute the else clause. Truthy values are any values that result in true when evaluated in a Boolean context like an if statement. Falsy values are values that evaluate to false in a Boolean context.
    • Conditional statements allow you to execute different blocks of code based on certain conditions.
    • Truthy values are values that evaluate to true in a boolean context, while falsy values evaluate to false.
    • The ternary operator is a compact way to write if/else statements. It has the syntax: condition ? expressionIfTrue : expressionIfFalse;
    • Example of if/else statements:

      let isRaining = true;
      if (isRaining) {
        console.log("Take an umbrella!");
      } else {
        console.log("Enjoy the sunshine!");
      }

    • Example of ternary operator:

      let isRaining = true;
      isRaining
      ? console.log("Take an umbrella!")
      : console.log("Enjoy the sunshine!");

    Binary Logical Operators

    • Logical AND (&&) checks if both operands are true and returns a result. If true, it returns the rightmost value.
    • Logical OR (||) checks if at least one operand is true and returns a result. If true, it returns the true value.
    • Nullish coalescing operator (??) returns the right-hand operand when the left-hand operand is null or undefined. Otherwise, it returns the left-hand operand.
    • Example:

      let x = 5;
      let y = 10;
      console.log(x && y); // Output: 10 (both operands are true)
      console.log(x || y); // Output: 5 (at least one operand is true)
      console.log(null ?? "default"); // Output: "default" (left operand is null)
      console.log(undefined ?? "default"); // Output: "default" (left operand is undefined)

    • Math.max(): Returns the largest of zero or more numbers.

    • Math.cbrt(): Returns the cube root of a number.

      • The formula for generating a random number between two values (inclusive) is:
      Math.floor(Math.random() * (max - min + 1)) + min

    Common Number Methods

    isNaN(): Checks if a value is NaN (Not a Number).

    Number.isNaN() provides a more reliable way to check for NaN values, especially in cases where type coercion might lead to unexpected results with the global isNaN() function.

    let value1 = NaN;
    let value2 = "Hello";
    console.log(isNaN(value1)); // Output: true
    console.log(isNaN(value2)); // Output: true (type coercion)
    console.log(Number.isNaN(value1)); // Output: true
    console.log(Number.isNaN(value2)); // Output: false (no type coercion)

    parseFloat(): The parse float method converts a string to a floating-point number.

    parseInt(): The parse int method converts a string to an integer.

    toFixed(): The to fixed method formats a number using fixed-point notation.
