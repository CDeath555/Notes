Elements

  • <h1></h1> - Header
    • <h1>This is an example</h1>
    • ranges from h1-h6
  • <a> </a> - Anchor element. used to create hyperlinks.
    • <a href="thisisanexamplelink.com"> This is an example</a>
  • <href=> - Specefies the URL of a link. OR a path on a computer.
    • <a href="C:/workspace/imgs/hellfire.jpg></a>
  • <img> - Prompts to pull an img. (this is a void element, which doesn't need a closing tag.)
    • <img src="C:/workspace/imgs/example" alt="This is an example">
  • <input> - Used to create various user-input data like text, password, checkboxes, and more.
    • <input type="password">
  • <link/> - Used to create external resources like site icons.
  • <main></main> - Used to show the main body of your HTML.
  • <section></section> - Used to define sections in a document.
  • <ul> - Creates an unordered list of items.
    • <ul> <li> example. </li> </ul>
