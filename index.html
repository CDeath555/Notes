Coding

Elements

  • <h1></h1> - Header
    • <h1>This is an example</h1>
    • ranges from h1-h6
  • <a> </a> - Anchor element. used to create hyperlinks.
    • <a href="thisisanexamplelink.com"> This is an example</a>
  • <href=> - Specefies the URL of a link. OR a path on a computer.
    • <a href="C:/workspace/imgs/hellfire.jpg></a>
  • <img> - Prompts to pull an img. (this is a void element, which doesn't need a closing tag.)
    • <img src="C:/workspace/imgs/example" alt="This is an example">
  • <input> - Used to create various user-input data like text, password, checkboxes, and more.
    • <input type="password">
  • <link/> - Used to create external resources like site icons.
  • <main></main> - Used to show the main body of your HTML.
  • <section></section> - Used to define sections in a document.
  • <ul> - Creates an unordered list of items.
    • <ul> <li> example. </li> </ul>
  • <li></li> - list element. Creates a list item.
  • <em></em> - emphasis element. Used to emphasize text.

Attributes

  • src=" " - Used to pull the image/video from a specific source
  • alt=" " - Used to provide descriptors in the code. accessibility purposes.
  • target="_blank">text here< - enables link to open in a new browser tab. the text in the brackets is to write the text you want the hyperlink to appear in.
  • type=" " - used to discern the specific type of nature of an element. like 'checkbox' , or mp4.
  • rel=" " - specify relationship between linked resource and HTML document. (Such as preconnect, or icon)
  • id=" " - an identifier attribute. Used to identify something. Should not be used more than once. NO SPACES in the identifiers. If you want to target a specific element, it is best to use id because those values need to be unique.
  • class=" " - like id, an identifier attribute. Can contain spaces. Classes are best used when you want to apply a set of styles to many elements.
  • controls - used with <audio> element.
    • example: <audio> src=" "> controls</audio>. it's also a boolean attribute
  • loop - boolean attribute which loops audio
  • poster=" " - when a video is loading, this image will display until the video loads example of audio with muted loop control
