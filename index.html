Attributes

  • src=" " - Used to pull the image/video from a specific source
  • alt=" " - Used to provide descriptors in the code. accessibility purposes.
  • target="_blank">text here< - enables link to open in a new browser tab. the text in the brackets is to write the text you want the hyperlink to appear in.
  • type=" " - used to discern the specific type of nature of an element. like 'checkbox' , or mp4.
  • rel=" " - specify relationship between linked resource and HTML document. (Such as preconnect, or icon)
  • id=" " - an identifier attribute. Used to identify something. Should not be used more than once. NO SPACES in the identifiers. If you want to target a specific element, it is best to use id because those values need to be unique.
  • class=" " - like id, an identifier attribute. Can contain spaces. Classes are best used when you want to apply a set of styles to many elements.
  • controls - used with <audio> element.
    • example: <audio> src=" "> controls</audio>. it's also a boolean attribute
  • loop - boolean attribute which loops audio
  • poster=" " - when a video is loading, this image will display until the video loads example of audio with muted loop control

Vocabulary

  • HTML entities
    • used to represent special characters in HTML
      • Named reference --> &lt; &gt; examples of the < and > tags.
      • Decimal numeric reference--> &#(number). &# 165
      • Hexadecimal reference--> Same idea, different execution. & #x20AC
  • Boolean Attribute
    • A boolean attribute in HTML that represents true or false values based on its presence or absence on an element.
      • example : <input type="checkbox" checked />
  • Inline element
    • Elements that do not start on a new line and only take up as much width as necessary, like <img>, <span>, and <a>
  • Block element
    • Elements that take up the full width available by default, like headers or paragraphs.

    • CSS notes

    The default styling for a lot of elements is "display: block." This ensures the element takes the full width of the container.

    Properties

    display: inline is used for smaller text patches in line, or specific styles or parts of a paragraph.

    display: inline-block utilizes both inline and block properties, allowing elements to sit inline while still accepting width and height values.

    Margin

    Margin-top: 10px; This adds space above each list item.

    • Utilizing this, I can target the spacing of items.

    Margin: 10px; applies the spacing to all four sides.

    Margin: 10px 20px; applies the spacing to the top/bottom and left/right respectively.

    Padding

    Padding is the space between the content and the border of an element.

    Padding: 10px; applies the padding to all four sides.

    Padding: 10px 20px; applies the padding to the top/bottom and left/right respectively.
