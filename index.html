    Vocabulary

  • HTML entities
    • used to represent special characters in HTML
      • Named reference --> &lt; &gt; examples of the < and > tags.
      • Decimal numeric reference--> &#(number). &# 165
      • Hexadecimal reference--> Same idea, different execution. & #x20AC
  • Boolean Attribute
    • A boolean attribute in HTML that represents true or false values based on its presence or absence on an element.
      • Example : <input type="checkbox" checked />
  • Inline element
    • Elements that do not start on a new line and only take up as much width as necessary, like <img>, <span>, and <a>
  • Block element
    • Elements that take up the full width available by default, like headers or paragraphs.
  • SVG
    • Scalable Vector Graphic, an image that can be scaled to any size without losing quality.
  • Absolute path
    • a complete link to a resource, starting from the root directory, ending at the file location.
      • Example: C:/workspace/images/example.jpg
  • Relative Path
    • A link that is relative to the directory of the current folder
      • Example: imgs/example.jpg
  • Pathing
    • You can use . or .. to access the current folder, or parent folder paths respectively.
      • Example: ./images/example.jpg, or ../worksheet2/images/example.jpg

    • CSS notes

    The format for styling is as follows:

    Selector {

        Property: Value;

    }

  • selector
    • Targets the specefic element to style.
  • property
    • Specefies which kind of styling will be applied
  • Value
    • Specefic setting applied to that property

    • There are three ways to style:

  • Inline CSS
    • When you apply the styling directly onto the HTML line.
  • Internal CSS
    • When you apply the styling in the <head> section of the HTML document.
  • External CSS
    • When you apply the styling via a separate CSS sheet. This is the most common method used.

    • The default styling for a lot of elements is "display: block." This ensures the element takes the full width of the container.

    Universal Selector ( * )

    This Selector applies to all elements on the page, however is overridden by all other style types. It's good for setting a default start point like Margin and padding to 0 for the page. The order of application is as follows: Inline CSS, Internal ID, External, Universal.

    There is a way to override the order of application, and that is with the !important declaration.

    Properties

    display: inline is used for smaller text patches in line, or specific styles or parts of a paragraph.

    display: inline-block utilizes both inline and block properties, allowing elements to sit inline while still accepting width and height values.

    Margin

    Margin is the space outside an element's border.

    Margin-top: 10px; This adds space above each list item.

    • Utilizing this, I can target the spacing of items.

    Margin: 10px; applies the spacing to all four sides.

    Margin: 10px 20px; applies the spacing to the top/bottom and left/right respectively.

    Padding

    Padding is the space between the content and the border of the element.

    Padding: 10px; applies the padding to all four sides.

    Padding: 10px 20px; applies the padding to the top/bottom and left/right respectively.

    JavaScript

    Data types:

    • number
      • Represents numeric values, including integers and floating-point numbers.(1, 5, 3.14) Used in console.log()
    • string
      • Represents a sequence of characters enclosed in single or double quotes. ("Hello", 'World') Used in console.log()
    • undefined
      • Meaning a variable has been declared, but not been given a value.
    • Null
      • Means the variable has intentionally been set to nothing.
    • object
      • a collection of key-value pairs.
    • symbol
      • is a special type of value in JavaScript that is always unique and cannot be changed. It's often used to create unique labels or identifiers for properties
    • BigInt
      • used for big numbers outside the limit of the <number> data type.

    Strings

    Strings are sequences of characters enclosed in single or double quotes. They can be manipulated using various methods and operators.

    To access a character from the string use a bracket notation and pass in the index number:

    let message = "Hello, World!";

    console.log(message[0]); // Output: H

    \n Newline. You can use this to create a new line in your string.

    let message = "Hello, World!";

    console.log(message + "\n" + "This is a new line.");

    Escaping strings

    let message = "He said, \"Hello!\"";

    console.log(message); // Output: He said, "Hello!"

    String Interpolation and Template Literals

    let name = "Alice";

    let message = `Hello, ${name}!`; // Using template literals

    console.log(message); // Output: Hello, Alice!

    Methods

    Functions are reusable blocks of code that perform a specific task. Like:

    • console.log()
      • outputs a message to the console
    • indexOf()
      • returns the index of the first occurrence of a specified value in a string or array. example: message.indexOf("here")
    • .slice()
      • returns a portion of a string or array based on specified start and end indices. example: message.slice(5)
    • .toUpperCase() / .toLowerCase()
      • converts a string to uppercase or lowercase letters. example: message.toUpperCase() or message.toLowerCase()
    • .replace()
      • replaces a specified value with another value in a string. example: message.replace("old", "new")
    • .repeat()
      • repeats a string a specified number of times. example: message.repeat(3) can also use words assigned as numbers.
    • .includes()
      • checks if a string contains a specified value and returns true or false. example: message.includes("here")
    • .trim(), .trimStart(), .trimEnd()
      • removes whitespace from the beginning and end of a string. example: message.trim()
    • .prompt()
      • displays a dialog box that prompts the user for input. example: message.prompt()

    Math

    Working with the Number Data type

    • Definition: JavaScript's Number type includes integers, floating-point numbers, Infinity and NaN. Floating-point numbers are numbers with a decimal point. Positive Infinity is a number greater than any other number while -Infinity is a number smaller than any other number. NaN (Not a Number) represents an invalid numeric value like the string "Jessica".

    Common Arithmetic Operations

    • Addition Operator ( + ) calculates the sum of two values.
    • Subtraction Operator ( - ) calculates the difference between two values.
    • Multiplication Operator ( * ) calculates the product of two values.
    • Division Operator ( / ) calculates the quotient of two values.
    • Remainder Operator ( % ) calculates the remainder of a division operation.
    • Exponentiation Operator ( ** ) calculates the power of a value.
